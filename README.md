# Посмотри в окно

Интерфейс поиска видеороликов с видами из окон разных городов. Учебный проект Яндекс Практикума.

[Репозиторий проекта](https://github.com/Saakoz14/posmotri-v-okno)

## Превью сайта

![Посмотри в окно — интерфейс поиска видео](./posmotri-v-okno-preview.png)

На снимке показано состояние ошибки получения данных. Приложение загружает видео из API Практикума; при недоступности этого сервиса список роликов и видео не появляются.

## Возможности

- Поиск видео по городу и времени суток.
- Переключение роликов и подгрузка списка.
- Кастомные чекбоксы, состояния интерактивных элементов и навигация с клавиатуры.
- Отображение загрузки и ошибок получения данных.

## Технологии

HTML5, CSS3, Flexbox и локальные шрифты Oswald и Fira Sans Condensed. Готовый JavaScript Практикума для работы с видео.
