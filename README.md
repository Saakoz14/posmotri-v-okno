# Посмотри в окно

Учебный проект Яндекс Практикума: интерфейс поиска видеороликов с видами из окон разных городов.

Репозиторий: https://github.com/Saakoz14/posmotri-v-okno

![Превью интерфейса «Посмотри в окно»](./posmotri-v-okno-preview.png)

## Технологии

- HTML5, CSS3, Flexbox.
- Локальные шрифты Oswald и Fira Sans Condensed.
- Кастомные чекбоксы, состояния интерактивных элементов и навигация с клавиатуры.
- Готовый JavaScript для поиска, переключения и подгрузки видеороликов.
